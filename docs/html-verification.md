## 范围与限制

浏览器自动化环境不允许导航 file://，因此没有把本地文件协议或各品牌浏览器的兼容性标为实测通过。实际页面交互使用只提供该 HTML 的本地预览端点。静态检查已确认 CSS/JavaScript 全部内联，没有外部脚本、字体或图片。应用计算与导出代码不发起网络请求；内嵌 Plotly 是完整发行包，包含未启用的联网图表功能，页面内容安全策略通过 connect-src 'none' 禁止其联网。三维工具栏仅保留本地图像导出和视角操作。计算与导出完全在页面内完成。

采用 Blob Worker 运行计算；Worker 不可用时自动退回分段计算。没有实测所有浏览器的回退路径。不同设备上的计算耗时不能与原 Python 性能基准直接比较。页面给出的耗时仅是当前浏览器这一次计算的观察值。
