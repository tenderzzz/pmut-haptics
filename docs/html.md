# 单文件 HTML 实验台

## 在线或离线打开

**在线运行：[pMUT 实验台](https://tenderzzz.github.io/pmut-haptics/)。**

**离线使用：[下载 pmut-haptics.html](https://github.com/tenderzzz/pmut-haptics/releases/latest/download/pmut-haptics.html)**，保存后用浏览器打开。完整项目 ZIP 与 Python 安装包见 [最新 Release](https://github.com/tenderzzz/pmut-haptics/releases/latest)。

GitHub 的 blob 文件页面用于查看源码，不是 HTML 运行入口；约 4.9 MB 的文件可能超出源码预览限制。在线演示由 GitHub Pages 提供，项目网址根路径的 index.html 与离线版来自同一份构建文件。

打开项目根目录的 **pmut-haptics.html**，或把这一个文件复制到另一台电脑，再用现代浏览器打开。文件中已经包含界面、计算程序和绘图代码，**不需要安装 Python、Node.js，也不需要启动本地服务**。第一次打开会自动计算默认实验。

建议先把文件保存到本地，再选择“用浏览器打开”。网盘、聊天软件或邮件的内嵌文件预览可能禁用 JavaScript；这类预览不等同于浏览器运行。页面本身不加载网络资源，只有主动点击文献链接时才会访问外部网站。

完整 Python 工程仍用于历史水中成像、随机相位误差、批量扫描、性能基准和大规模计算。HTML 使用独立的 JavaScript 实现，并通过逐点数值对照保持模型一致。

## 演示流程

1. 查看默认声场、142.72 Pa RMS 声压、约 19.26 μN 的有限平面合力和约 10.26 mm 的声压 −6 dB 宽度。
2. 在声场图下方查看“阵列几何与目标位置”：拖动旋转、滚轮或双指缩放，悬停查看坐标和相位；使用俯视、侧视、重置视角，或相机按钮保存 PNG。阵元颜色对应设定焦点的驱动相位，橙色表示目标或整条路径。三轴使用相同长度比例。
3. 在“实验对比”保存基准，把峰值表面振速从 1 改为 0.5 m/s，再运行。声压约变为 71.36 Pa，合力约变为 4.82 μN，宽度基本不变。
4. 选择圆形轨迹并运行，在“调制与移动”播放或逐帧查看。动画展示未调制辐射压，下面的波形单独展示低频包络产生的合力变化。
5. 在“模型与导出”保存配置和数据。TOML 可以交给完整 Python 工程继续复现。

点击焦平面可以设定新的 x/y 焦点，也可以直接输入坐标。修改参数不会立即替换图表，提示条会指出仍在显示上一次结果。运行过程中可以取消，已完成的结果会保留。

## 功能与范围

| 项目 | HTML 版 |
| --- | --- |
| 阵列 | 均匀或 Hann 加权；每方向 1–32 个阵元；间距不超过 1λ |
| 频率与振速 | 20–600 kHz；0–10 m/s 峰值表面振速；阵元不可重叠 |
| 场图 | 等比例焦平面 RMS 声压/辐射压、x-z 截面、主瓣剖面、阵元相位 |
| 三维几何 | 阵列与目标坐标、静态/直线/圆形路径；旋转、缩放、悬停坐标和相位、俯视/侧视/重置、PNG 导出 |
| 刺激 | 连续波、脉冲、正弦幅度调制；静态、往复直线、圆形轨迹 |
| 采样 | 每轴最多 151 点；轨迹最多 121 帧；包络最多 20 万点 |
| 导入 | 本项目 JSON / TOML 配置；HTML 面板要求平面 nx = ny |
| 导出 | 配置 JSON / TOML、指标 JSON、全部数据 JSON、焦平面 CSV |
| 对比 | 当前结果与一组基准；仅保存在当前页面内存中 |
| 不包含 | 随机相位误差、历史水中 DAS 成像、批量扫描和 Python 性能基准 |

导入的文件仍受 HTML 的输入范围和计算规模限制。TOML 导入器面向本项目的简单配置格式，不是通用 TOML 解析器。不同字段的计算限制会明确提示，不会静默忽略随机相位误差。

默认 HTML 平面网格为 81×81，Python 正式预设为 101×101。由积分和阈值插值产生的末位差异属于采样差异；需要精确对照时应使用同一份导出配置。页面显示的是有限区域上的模型估算，未经过电压—振速标定或人体感知验证。

## 保存与复现

所有导出针对**最近一次已计算的结果**。参数改动后应先重新运行。关闭页面会清空当前实验和对比基准，因此重要实验需要主动导出。

完整数据 JSON 中，复声压拆成 `field.re` / `field.im`，单位为峰值 Pa；二维场按行展开为 (ny, nx)，x-z 截面为 (nz, nx)，轨迹为 (frame, ny, nx)。坐标使用米，时间使用秒。CSV 含 x_m、y_m、pressure_rms_pa、radiation_pressure_pa 四列。

用导出的 TOML 在 Python 工程复现：

```sh
.venv/bin/pmut-haptics run --config pmut-config.toml --output outputs/from-html
```

导出的全部数据可能明显大于 HTML 文件本身。默认圆形实验包含 41 个平面和高采样率调制波形，实际检查的 JSON 约 10.9 MB。

## 开发与测试

维护源码在 web/，交付文件在根目录。修改后重新生成：

```sh
.venv/bin/python scripts/build_html.py
.venv/bin/python -m pytest tests/test_html.py -q
```

三维视图使用随项目提供的 Plotly.js 4.1.1，源码位于 web/vendor/，MIT 许可证一并内嵌。其余场图使用原生 Canvas。完整 HTML 约 4.9 MB，不访问 CDN，也不上传实验数据。三维图需要浏览器支持 WebGL；无法初始化时会提示，其他计算、场图和导出仍可使用。

生成只需要 Python 标准库；数值对照测试需要项目开发环境和 Node.js。Node 仅用于开发检查，不是打开 HTML 的依赖。CI 显式准备 Node，避免意外跳过数值对照。

可选的开发预览：

```sh
.venv/bin/python scripts/preview_html.py
```

该预览仅在 127.0.0.1:8765 提供这一份 HTML，不列目录、不提供项目其他文件。预览支持并发请求，浏览器建立空闲预连接时不会阻塞新的页面请求。它只用于开发检查，交付文件不依赖它。

实际验证范围与导出校验见 [HTML 验证记录](html-verification.md)。
