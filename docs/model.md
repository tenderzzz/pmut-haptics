# 模型与数值约定

## 计算范围

主线以给定的阵元表面振速计算空气声场，继而估计近似法向入射下的表面辐射压。pMUT 的实际弯曲振型用均匀振动的障板圆活塞近似。尚未实现多层压电机电耦合、驱动电路、阵元互耦、反射面改变声场的反馈或皮肤力学。

默认空气参数为声速 343 m/s、密度 1.2 kg/m³。它们是固定示例值，没有根据温湿度自动修正。衰减系数由用户以 Np/m 输入，作用于声压幅度，默认 0。

## 声压、相位与阵列

采用时间约定：

```math
p(\mathbf r,t)=\Re\{P(\mathbf r)e^{i\omega t}\},\qquad k=2\pi f/c.
```

第 n 个圆活塞对场点的单位振速传递函数为：

```math
H_n(\mathbf r)=\frac{i\rho c k a^2}{2R_n}
\frac{2J_1(ka\sin\theta_n)}{ka\sin\theta_n}
e^{-ikR_n-\alpha R_n},\qquad P=\sum_n H_n u_n.
```

Jinc 在零点取极限 1，保留其符号。阵元位于 z=0，法向朝 +z；场点必须位于所有活塞前方。阵列坐标关于原点居中，间距 d=(d/λ)c/f。

指向目标点的振速相量：

```math
u_n=u_0 A_n\exp\{ik(R_{n,f}-\min_j R_{j,f})+i\epsilon_n\}.
```

因此传播负相位与驱动正相位在焦点相消。历史代码把虚数放入 phase 后又乘 i，使相位变成了实数衰减，详见来源审计。当前误差 ε 按固定 seed 生成，每次改变焦点时保持同一组阵元误差。

Hann 加权满足 ΣA²=N，保持与均匀加权相同的振速平方和。**这不等价于相同电功率或相同声功率**，因为项目没有电机耦合与辐射阻抗模型。

这里的远场近似针对**单个阵元**。阵列到场点的各个球面传播距离仍分别计算，并非把整个阵列当作远场平面波。极近场或大阵元条件应使用完整表面积分检查。

## 独立参考积分

`rayleigh_disk` 在圆盘半径上使用 Gauss–Legendre 积分，在方位角上周期积分：

```math
P(\mathbf r)=\frac{i\rho cku_0}{2\pi}\int_S\frac{e^{-ik|\mathbf r-\mathbf s|}}{|\mathbf r-\mathbf s|}\,dS.
```

轴线上有解析解：

```math
P(z)=\rho c u_0\left(e^{-ikz}-e^{-ik\sqrt{z^2+a^2}}\right).
```

代码用 expm1 避免小相位差相减损失。独立积分、轴向解析解和快速核的比较记录于 [验证数据](results/validation.json)。三个选定空气场点的快速核相对 L2 误差约 0.37%；该结论限于这些点和参数，不能推广到任意近场场景。

## 从声场到刺激

计算内核返回**峰值复声压**，不是 RMS。针对正弦稳态载波：

```math
p_{\rm rms}=|P|/\sqrt2,\quad
I\approx p_{\rm rms}^2/(\rho c),\quad
\Pi\approx\kappa I/c,\quad
F_A=\iint_A\Pi\,dx\,dy.
```

κ=1 对应吸收极限，κ=2 对应理想反射极限。本项目取 κ=2；公式采用近似局部行波和法向入射假设，没有逐方向计算动量通量。它在聚焦场中的使用是工程近似。这里的 P 是入射自由场声压，没有把反射后的总声压再次代入而重复放大。

辐射压模型依据 [Iwamoto 等的原始论文](https://hapislab.org/public/hiroyuki_shinoda/research/pdf/08Eurohaptics_iwamoto.pdf)。输出 F_A 只积分配置给定的有限目标平面，默认 x、y 均为 ±20 mm；它不是全空间总辐射力，也不是实测手指受力。

SPL=20log10(p_rms/20 μPa)。它是空气参考声压下的计算结果。修改介质为水后，不能将该参考值误当成水声常用参考值；水中历史复现有独立入口，主界面面向空气。

## 幅度调制与移动触点

包络 m(t) 乘在振速/声压幅度上，因此辐射压和力乘 **m(t)²**：

- 连续波：m=1。
- 脉冲：m=(1-depth)+depth·gate，gate 的占空比由配置决定。
- 正弦调制：m=(1-depth)+depth·(1+sin(2πf_m t))/2。

depth=1 时，50% 占空比脉冲的平均平方包络为 0.5，正弦包络为 3/8。正弦驱动幅度的平方还含 2f_m 分量，不能把载波 RMS、包络和辐射力幅度混用。

载波采用相量计算，不以低频时间网格采样 109.4 kHz 声波。包络采样率独立设置，至少为调制频率 20 倍。移动几何使用较少的轨迹帧，声场帧不含低频闪烁；慢变焦点响应插值到高采样率包络时间轴后，再乘 m²。避免用几十帧/秒的动画采样 100 Hz 调制。

直线是正弦往复；圆形以恒定角速度运行。duration_s 是完成 loops 次往复/绕行的时间，包含首尾相同的端点。时间平均运动图通过时间梯形积分得到，明确标为**未调制**，而不是直接把帧平均当成真实瞬时刺激。

所有静态指标对应配置中心焦点。运动数组和随时间指标另行保存。阵列指令的几何焦点与实际声压最大值可能不同；目前提供目标平面内的横向误差，不保证三维声场峰值恰在指定 z。

## 宽度与旁瓣

声压 −6 dB 采用幅度阈值 10^(−6/20)，辐射压 FWHM 采用压力峰值的 1/2。两者不是同一指标。沿选定峰值向左右寻找连续主瓣的阈值交点，以线性插值求宽度；触及视野边界则返回 null 和 clipped=true，不把显示范围当成完整宽度。

旁瓣水平在主峰两侧最近局部极小值之外，查找视野内最大的局部峰。没有足够的极小值或旁瓣时返回 null。它不是整三维空间的最坏旁瓣或扫描全范围的栅瓣保证。

## 水中成像保留模块

历史复现保留报告的水介质、1×8 线阵和五个散射点。修正版使用：
1. 包含发射、接收、成像区域和脉冲尾部的几何自适应时间窗口；
2. 具有明确脉冲中心的有限 Gaussian 正弦脉冲；
3. RF 的 Hilbert 解析信号、分数延时线性插值、复数求和后取幅值；
4. 单独模拟每个散射点，分别提取真正的孤立 PSF。

在保留 22.96 kHz 载波和 3 周期包络宽度时，轴向响应很宽，当前 ROI 内各孤立 PSF 的轴向半高交点不全，宽度标为截断。该模型不能据此宣称五点清晰分辨。它作为信号处理与回归案例，和空气触觉主线分别展示。

## 薄板计算的用途

`plate_frequency` 保留均匀圆薄板的 D=Eh³/[12(1−ν²)] 与基频估算，用于教学和原结果回归。Sone 文献中的 55/75 μm 为 Si 膜厚，PLZT 薄膜为 2 μm。以单一 PLZT 材料替代整个复合结构只属于历史简化，不能视为文献器件谐振频率的预测。
