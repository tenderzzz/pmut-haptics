## 简历条目候选

**pMUT 空中超声触觉仿真平台｜Python / NumPy / SciPy / JavaScript**

- 基于实习中的 pMUT 声场、相控聚焦与 DAS 成像代码，扩展二维空气阵列和幅度调制模型，建立从配置、声场到表面辐射压与有限区域合力的计算流程。
- 将脚本整理为 Python 包、命令行和交互实验台，加入 TOML 参数校验、固定种子、结果导出与复现文档；通过 43 项自动化用例，覆盖解析解、历史回归、界面流程及 HTML 与 Python 的 6 场景数值一致性。
- 对同一声场核实现 NumPy 分块向量化，在本机三档测试中相对逐点参考实现获得 3.12–9.32 倍中位耗时加速，并保存重复样本、数值误差和内存记录。

**0:00–0:30，问题与输入。** 直接打开单文件 pmut-haptics.html：目标是在给定阵列几何和表面振速时，比较空中触点位置、大小与刺激波形。说明振速未用电压标定，第一版没有皮肤力学。

**0:30–1:10，解释一张图。** 默认静态触点，指出峰值声压、RMS 声压与辐射压的关系。声压约 10.26 mm 的 −6 dB 宽度与辐射压约 7.53 mm 的半高宽不同，因为辐射压正比于声压平方。

**1:10–1:45，参数对比。** 保存当前结果，改为 Hann 加权并运行，比较主瓣和峰值。解释加权保持振速平方和，但不等于等电功率。再切换圆形轨迹，指出动画与 100 Hz 调制的时间采样分开。

**1:45–2:25，正确性。** 展示解析解、完整表面积分和快速核的验证表；解释 0.37% 是三个指定点的近似误差，而约 10⁻¹⁶ 是数值实现一致性。说明发现了历史相位的双重 i 问题，以及表 5 无法按附录重现。

## 常见追问与回答要点

| 追问 | 应能讲清的内容 |
| --- | --- |
| 为什么选 pMUT？ | 从已有实习成果出发；当前软件将膜面近似为均匀圆活塞，还没有完整压电器件模型 |
| 复声压里的正负号如何确定？ | 固定 exp(+iωt)，传播 exp(−ikR)，驱动 exp(+ikR_f)，在目标点相位相消 |
| −6 dB 与 FWHM 一样吗？ | 幅度 −6 dB 约 0.501 倍；辐射压 FWHM 对应声压约 0.707 倍 |
| 声压翻倍，力如何变化？ | 在相同介质、反射假设和面积下，辐射压与力约变为 4 倍 |
| 脉冲与正弦包络如何平均？ | 对 m² 平均；满深度 50% 脉冲为 0.5，正弦为 3/8 |
| 怎么证明不是“快但算错”？ | 同模型双实现回归，加独立表面积分、轴向解析解、对称性等物理检查 |
| 为什么不把 79.83→32.96 mm 当提升率？ | 两边包括错误修正和度量变化，不能当同条件的硬件分辨率优化 |
| DAS 为什么先做 Hilbert？ | 实正弦在回波中心可能过零；解析信号保留相位与包络，分数延时后相干求和 |
| 参数扫描为什么要归一化？ | 固定每阵元振速会使总驱动预算随数量增加；必须交代比较口径 |
| 圆形轨迹为什么像圆盘？ | 路径采样不等于空间分辨率，较宽的触点会互相覆盖 |
| 误差、实物和感知之间还有什么缺口？ | 器件振型/电压标定、介质和反射边界、实测声场、真实受力与触觉实验 |

## 面试前必须亲手完成的练习

1. 从新环境安装并运行 quick 和完整测试，解释输出每个文件的用途。
2. 把振速从 1 改为 0.5 m/s，验证声压减半、辐射压和力变为四分之一。
3. 改变焦点位置，说明相位如何变化，以及实际峰值为何可能偏离目标点。
4. 运行相位误差或 Hann 实验，提出能被图表证伪的判断。
5. 在代码中定位相位权重、分块声场、连续主瓣宽度与 DAS 插值，并能不用 AI 解释核心计算。
6. 重新运行 benchmark，用自己的机器结果替换简历数字，保留原始记录。

## 下一步的合理扩展

优先做振速/电压标定接口与实测声场数据对比，才有条件讨论具体器件的输出。皮肤力学、人体感知和实时硬件驱动属于后续阶段。已有本地三篇文献可作为背景和技术对照，但电渗泵、接触式 pMUT 与空气非接触超声的成果应分别表述。
