## 发现并修正的问题

| 问题 | 证据 | 修正 |
| --- | --- | --- |
| 聚焦相位重复乘 i | 最外阵元权重幅度约 0.000782，而理想纯相位控制应保持幅度 | 统一 exp(+iωt) 约定，采用实数相位角，验证焦点相干叠加 |
| 离轴圆盘积分缺方位角 | 对称点 x=±1 mm、z=0.5 mm 的声压比约 2.8449 | 完整二维极坐标表面积分，对称点比恢复为 1 |
| 声压/振速跨介质反推 | 水中计算与空气 SPL 124 dB 的测量条件不一致 | 原算术留在历史指标，主线采用显式、未标定振速输入 |
| RF 记录过短 | 148 点，末时刻 147.447 μs；最迟回波中心 180.971 μs，320 条路径中 34 条落在窗口外 | 按几何与脉冲支持时长确定记录，修正版 691 点 |
| DAS 最近邻实正弦采样 | 回波中心处的正弦值可能接近零；全局 fs 隐式依赖 | Hilbert 解析信号、显式时间轴、分数延时插值 |
| abs 被当作包络 | 对实数采样求绝对值不等于解析信号包络 | 复数波束合成后取幅值 |
| 宽度跨多个波瓣 | 原算法取全部过阈值点首尾位置 | 连续主瓣、交点插值、边界截断标记 |
| 多目标截面被称作 PSF | 五点叠加响应相互干扰 | 每个散射点独立模拟，单独计算 PSF |
| 膜厚材料混用 | 文献 55/75 μm 是 Si 膜，PLZT 为 2 μm | 均匀 PLZT 板仅保留为历史教学近似 |

修正水中模型的聚焦 −6 dB 宽度约 32.959 mm，原程序同类截面约 79.833 mm。此变化包含模型与度量修正，**不能包装为算法加速、硬件分辨率提升或经实验验证的改善比例**。可公平量化的速度提升另用相同物理核测试。
