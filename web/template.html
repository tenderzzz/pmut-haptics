从声场到表面刺激

二维阵列的复声压经相位聚焦后，换算为 RMS 声压。采用近似局部行波与法向入射条件，估算辐射压，并对有限目标平面积分得到合力。

pRMS = |P| / √2
I ≈ pRMS² / (ρc)
Π ≈ κI / c
FA = ∫A Π dA

低频包络 m(t) 作用于振速与声压，辐射压和合力随 m(t)² 变化。轨迹帧与包络波形分别采样，避免把动画帧率当成调制采样率。

如何理解这些数字

  • 合力只覆盖当前显示的有限平面，不是全空间总力。
  • 声压 −6 dB 宽度和辐射压半高宽是不同指标。没有完整交点时显示“超出视野”。
  • 路径可以很细，实际触点仍受波束宽度限制。默认圆形路径的时间平均刺激未必是清晰的空心圆。
  • 没有模拟皮肤力学、真实触觉阈值、驱动电压标定或硬件闭环。

离线版本的范围

保留空气触觉的参数调整、声场、调制、轨迹、对比和导出。每方向最多 32 个阵元、每轴 151 个网格点、间距不超过 1λ；随机相位误差和历史水中成像请使用完整 Python 工程。导出的 TOML 可由 Python 版直接读取。数值对照记录随项目提供。

默认阵元数量、半径与载波参考 Pala 等的非接触 pMUT 研究；辐射压模型参考 Iwamoto 等。间距、焦距和振速是示例假设。只有主动点击这些文献链接时才会访问网络。
