# 单文件实验台设计

交付目标：一个可直接打开、离线计算的 HTML，避免把本地服务地址当成可转发的网页。

界面以声场为主体。左侧是紧凑的实验参数，右侧先呈现可点击的等比例焦平面图，再给出数值读数；竖直截面和剖面用于解释结果。运动、对比、说明通过明确的页签切换。小屏把参数折叠到顶部。

颜色：纸面 #f3f7fb，图面 #ffffff，正文 #15364c，操作 #146f84，焦点标记 #dd7b22，辅助文字 #73879a。热图采用独立、顺序递增的色标，颜色只编码声压或辐射压。
字体：本机 PingFang SC / Microsoft YaHei / Segoe UI。标题 28px，正文 15px，数值 28px；不用远程字体。
布局：
```
参数栏 | 标题与运行、导出
       | 焦平面热图          指标 / 几何
       | 竖直截面           主瓣剖面
```

审查：不添加宣传首屏、无意义大数字或重复卡片。保留实验仪器的参数—读数关系，图面必须等比例。计算进度、旧结果提示、无信号和取消计算需要可见反馈。

实现：原生 Canvas 场图、内嵌 Plotly 三维几何、内联 CSS/JavaScript、Blob Worker；Worker 不可用时自动分块计算。无 CDN、无字体或图片网络依赖。HTML 主线支持空气触觉；历史水中成像仍由 Python 工程提供。

## 三维几何视图补回

沿用现有仪器界面的字体和蓝灰配色。在焦平面与指标下方增加一幅独立的三维“阵列几何与目标位置”，使阵列平面、焦点高度和移动路径能一起观察；竖直截面与主瓣剖面继续放在其后。视图三轴等比例，不以视觉拉伸暗示几何变化。

直接使用原 Python 实验台同版本的 Plotly Scatter3d：相位色阵元、橙色目标轨迹、悬停坐标、拖动旋转与缩放。提供重置、俯视、侧视按钮，键盘用户也能切换观察方向。只用最近一次已计算的配置与路径，修改参数时与其他图保持一致。

Plotly 及 MIT 许可证随单文件内联，不访问 CDN。原生 Canvas 继续绘制其他声场图。三维图初始化失败只影响这一视图，不能阻止计算与导出。文件体积增加到约 4.9 MB，换取与原版一致的三维交互。三轴按真实坐标范围等比例归一化，避免狭长场景被默认相机裁切；工具栏纵向排列，给窄屏图例留出空间。
